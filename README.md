# Aegisnir's Claude plugins

Every Claude Code plugin by Aegisnir, in one place.

| Plugin | What it does | Repo |
| --- | --- | --- |
| `manapool` | The real tokens behind Claude Code's 5-hour and weekly limits | [aegisnir/manapool](https://github.com/aegisnir/manapool) |
| `runenir-theme` | Runenir look for the Claude desktop and mobile apps, in nine gemstone colours | [aegisnir/runenir-claude-theme](https://github.com/aegisnir/runenir-claude-theme) |

## Add them

In the desktop app: click **+** next to the prompt box, then **Plugins**, **Add marketplace** with `aegisnir/claude-plugins`, then add the plugins you want.

At the prompt of a Claude Code terminal session:

```
/plugin marketplace add aegisnir/claude-plugins
```

Then install one:

```
/plugin install manapool@aegisnir-plugins
```

Each plugin's own repo has its README and licence.
